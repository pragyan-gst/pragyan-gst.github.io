GST Pragyan v5 visual refinement notes

1. Removed orange as a website UI colour. The orange in the GST Pragyan logo remains unchanged because it is part of the supplied brand asset.
2. Interface accents now use navy, teal, green and rose states.
3. Increased base reading size and adjusted headings, navigation, reference text, tables, calculator labels, cards and footer text for improved visibility.
4. Kept reading columns controlled while allowing large tables and working areas to use available desktop width.
5. Simplified hero decoration by removing the floating orange accent point and retaining restrained green geometry.
6. Preserved the actual GST Pragyan application screenshot.
7. Maintained reduced-motion support and visible keyboard focus states.
8. No em-dash or en-dash characters are used in the website text.

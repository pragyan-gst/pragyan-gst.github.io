GST Pragyan Desktop

From downloaded returns to a usable working file.

The desktop application is built for the data that already exists on a taxpayer's or officer's computer. It does not need a portal login and does not send the loaded files to a server.

01ImportGSTR-1, 3B, 2A, 2B, 9, 9C, IFF and e-Way Bill files.
02MergeBring periods and return types into a consistent working dataset.
03AnalyseRun scrutiny parameters and return-to-return comparisons.
04ReconcileMatch purchases and examine ITC and e-Way Bill patterns.
05ReportPrepare working papers and an ASMT-10 reference draft for review.

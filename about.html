Why this exists

It started because I kept looking up the same things, getting them slightly wrong, and rebuilding the same spreadsheet.

I work on GST — return scrutiny, enforcement and adjudication. The questions that come up are not complicated ones. What was the late fee for a period in 2019? Is a notice for FY 2019-20 still within time? Which notification changed that cap? They are simple questions with answers scattered across eight years of notifications, and getting one of them slightly wrong means a figure in a notice that does not hold.

So I started writing the answers down properly, with the provision beside each one. That became the charts. The calculators came next, because working out a late fee by hand across three rate changes is exactly the sort of thing a person gets wrong at five in the evening. Then the desktop tool, because reconciling five years of returns in a spreadsheet is worse.

What I try to get right

Every figure names its source. A number without the notification behind it cannot be used in a notice or a reply, so there is no point publishing one. Where the position is unsettled — a notification under challenge, a date that rests on an extension — the page says so rather than presenting it as fixed.

Where something cannot be established, it says so. That applies to the tool as much as the charts. A screen that reports nothing because the data was missing is not the same as one that examined the data and found nothing, and conflating the two is how a clean result gets read into a defective file.

Mistakes get corrected in public. There have been several. A late fee cap that was double what it should have been, a rate that was silently misread because a file name matched too loosely, an evidence total that disagreed with the demand it was supporting by a rupee. Each was found by someone checking, and each is written up in the release notes rather than quietly patched.

What this is not

It is not advice, and it is not official. It is an independent working aid, made in my own time, and it is not published by or connected with any government body. It has no account system, collects nothing about you, and asks for no money.

If you use it and something is wrong — a figure, a date, a citation, a sentence that reads badly — I would rather hear it than not. Get in touch.
